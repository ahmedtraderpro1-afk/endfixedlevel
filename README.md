# Jewelry By Nadia

GitHub-ready Vite + React project with uploaded jewelry images placed into homepage sections.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Hero uses approved existing assets in `public/assets/jewelry/hero-approved.jpeg` and `hero-mobile-approved.png`.
- Uploaded jewelry images are organized inside `public/assets/jewelry/uploads/`.
- Image placement summary is documented in `ASSET_MAP.md`.
